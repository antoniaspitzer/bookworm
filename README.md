# bookworm
Eine app mit flutter für Menschen die sich ihre Bücher tracken wollen


konzept:


startseite mit kleinen Daten: 
letztes buch gelesen, wieviele bücher insgesamt
wieviele bücher auf to be read

buch zu seiner liste hinzufügen:
man kann foto von cover machen, Titel und opt 
beschreibung reinpacken. höchste seitenanzahl
und autor usw.

während buch lesen kann man immer wieder den
fortschritt einsehen sofern man de seitenanzahl
eingetippt hat. 

zum schluss bewertungen schreiben möglich.
